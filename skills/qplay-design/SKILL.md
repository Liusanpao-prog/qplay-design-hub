# QPLAY Design｜轻量 Skill（2026-11-03 重启）

## 使用边界
- 不继承旧仓库或旧聊天中的既有视觉结论。
- 必读当前分支：`brand/BRAND-BASELINE.md`、`WORKFLOW.md`、`DESIGN-CHECKLIST.md`。
- 品牌标识与商用素材以用户本轮提供或新版本明确确认的文件为准。
- 实际价格、色号、IP形象、效果图、墙面实测尺寸不得凭空补齐。

## 输出顺序
1. **设计简报**：提炼用途、目标、限制和待确认事项。
2. **视觉方向**：概念、信息层级、版式、色彩、字体和画面焦点。
3. **生成/制作描述**：清楚指出画面比例、元素关系、真实素材占位、可施工性。
4. **检查与修改**：按质量检查表校对中文、尺寸、AI瑕疵和品牌一致性。
5. **正式交付**：只有通过审核的版本才能被视为正式设计资产。

## 审美原则
优先清晰与节奏；少即是多；高级感来自真实的版式与细节，而不是元素堆砌。允许风格创新，但不得伪装成已确认的品牌规范。
