# QPLAY Professional Visual Design

## 0. 使用边界和资料优先级

这是**设计工作流程**，不能取代品牌方核准的 Logo、IP、色值、字体授权或施工实测图纸。

在任务开始前，优先读取本仓库的：
- `01-brand-guidelines/README.md`、`logo-rules.md`、`design-tokens.md`
- `02-ip-characters/README.md`（涉及角色时）
- `03-spatial-visuals/wall-projects.md`（涉及场地时）
- `04-design-deliverables/README.md`（涉及印刷物料时）
- `05-web-development/README.md`（涉及网站时）

若工具没有文件访问权限，请明确说明并请用户提供必要资料，不要假装已经读取。

## 1. 品牌底线

1. 正式中英文名称为 **QPLAY 趣能运动超乐场**；不得改成旧名。
2. 品牌气质：成熟、干净、明亮、年轻运动感，主色角色为能量橙、银灰、暖白/浅灰，少量深石墨灰。精确色值以核准色卡为准，**不要猜 HEX/CMYK**。
3. 不做儿童乐园式幼稚卡通、廉价霓虹、赛博朋克/电竞网吧、大面积黑色或过多伪3D装饰。
4. 正式 Logo 以原始矢量文件为准；不得靠生成图重新拼写 Logo 或擅自改字形。
5. 五位 QPLAY CREW 以用户最终确认的原图为唯一角色基准。严禁改脸、混配眼镜/帽子或改变角色身高体系；没有原始素材则先制作安全布局或占位说明，不虚构“官方原稿”。
6. 信息传达优先：文字完整、基线统一、留白舒适、识别距离足够，不能为了动势牺牲中文字形和可读性。

## 2. 标准工作流

### 阶段A：识别任务
写出：用途、品牌、尺寸与单位、横竖方向、实际观看距离、目标受众、最终文案、交付格式、参考风格、禁忌项、截止节点。
已有信息直接沿用；仅在关键数据确实缺失且无法合理开展时询问。

### 阶段B：分析与参考
区分“必须保持的品牌资产”“可探索的视觉方向”“必须准确的文案”。
研究 2–3 个有来源的专业视觉参照，说明借鉴点（留白、层级、材质、节奏），禁止照搬受版权保护的成品。

### 阶段C：创意方向
明确一个主视觉中心、一个主信息层级、两个以下辅助层级。
给出构图草案的文字说明：主标题位置、主体比例、留白区域、Logo 安全区、正文与 CTA、预期材质感；避免无必要的多方向堆砌。

### 阶段D：制作
先输出可执行的画面描述或结构稿；在用户要求生成图像时，使用有权限的图像工具制作。
海报与墙面：优先检查文字、比例、留白和可施工性。
网页：先定内容架构、设计系统、响应式布局，之后实现。
若用户要求透明背景、可编辑分层、源文件或精确矢量图，需以**实际产出能力**为准，不用静态预览冒充完整可编辑文件。

### 阶段E：三道质量门槛
1. **文字与品牌关：** 字形无缺笔、文案无错字、价格/日期/规则无误，Logo/IP 使用正确。
2. **视觉关：** 视觉主次鲜明、统一且克制；无过量速度线、碎片化装饰、过度锐化及明显重复元素。
3. **交付关：** 比例/尺寸/出血/分辨率/颜色模式/文件名、版权、现场结构与实际材料可复核。

每次出稿对照 [设计质量检查表](./references/design-review-checklist.md)。

## 3. 不同任务的专项标准

### KV海报与社媒视觉
主标题必须远距离清晰；文案准确优先于复杂装饰；避免以渐变、光效和粒子弥补排版缺陷。真实促销价格或活动规则不得推测。

### IP与文创
保留官方角色脸型、服装逻辑、帽子、眼镜和体态。群像高矮层级：炭黑狐115% > 银白狐105% > 橙狐100% > 焦糖棕狐90% > 奶油浅粉狐85%；新装饰不得遮挡核心识别。

### 店内空间、导视、墙面
严守实测尺寸、门洞、通道、拼缝及装配条件；概念效果图不等于施工图。现实材质优先；墙面文字不遮挡门/检修口。

### 艺术字
首先保证每个汉字**笔画完整准确**，统一字高、基线、字重及倾斜角；飞镖/靶心元素只作克制点缀。涉及“瞄准热爱 镖中精彩”时必须单行横向排版，不能缺笔画。

### 品牌手册与 PPT
标题、正文、说明、图注层级清楚；16:9 宽屏；品牌手册遵从已确认的18页大纲，不擅自复用被否决的旧封面构图；不得伪造案例和业绩。

### 官网与界面
参考真实优秀界面设计；响应式、对比度、阅读节奏、加载速度和导航优先，移动端先行。品牌地址、电话、票价均需有正式来源。

## 4. 回复/交付格式

1. **任务理解：** 重述尺寸、主要文字、限制和最终用途。
2. **创意方案：** 视觉方向、构图逻辑、颜色/材质、文字布局。
3. **制作交付：** 生成图/文案/代码或可实施的制作提示词。
4. **质检结论：** 已核对项、未能核验项、需要用户原始素材的项。

用户明确要求直接制作时，尽可能减少无必要的重复确认；在拿不到官方原图或无法交付某种编辑格式时，应透明说明限制。
