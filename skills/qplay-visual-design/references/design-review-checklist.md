# 商业视觉设计质量检查清单

## A 文字与信息
- [ ] 中文字形正确，笔画无缺失、无乱码
- [ ] 英文无错误、字号足够；标题/副标/正文层级清晰
- [ ] 价格、日期、活动规则、尺寸和单位均核对过
- [ ] 需要后续补字的区域已按要求预留

## B 品牌与角色
- [ ] 中文名“趣能运动超乐场”正确
- [ ] QPLAY 官方 Logo 未擅自重绘、变形或加入无批准效果
- [ ] 颜色按已确认标准使用（无官方色值时注明待核）
- [ ] 使用最终版 IP 原图；五位狐狸的比例、脸、服饰和眼镜准确
- [ ] 不出现儿童乐园感/赛博朋克/网吧感/廉价过量特效

## C 构图与视觉
- [ ] 只有一个明确主焦点
- [ ] 主次关系清晰，文字可远距离阅读
- [ ] 适度留白，没有多余飞线/碎片/大面积几何装饰
- [ ] 主视觉与参考方向一致但非照搬
- [ ] 视觉元素数量、光影和纹理没有过载

## D 印刷/空间/网页交付
- [ ] 尺寸比例、横竖方向正确
- [ ] 门洞、柱、设备、拼接缝、视线和安全留白已记录
- [ ] 分辨率、出血、色彩模式、材质由制作端确认
- [ ] 可编辑格式与实际文件能力一致，不以图片假装分层原稿
- [ ] 对外公开的图片/字体/品牌资产已经获得许可
- [ ] 网站包含移动端验证、链接检查和可访问性核验
