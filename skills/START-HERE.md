# 零基础教程｜怎么用 QPLAY 的视觉设计 Skill？

## 路线 A：你只在 ChatGPT 网页/客户端中工作（最简单）

**不需要安装任何软件。**

第一步：打开本仓库里的 [SKILL.md](./qplay-visual-design/SKILL.md)。

第二步：在 ChatGPT 新对话里发下面这句话（可以直接复制）：

> 请先通过已连接的 GitHub 插件读取仓库 `Liusanpao-prog/qplay-design-hub` 中 `skills/qplay-visual-design/SKILL.md`，以及该文件提到的设计质量检查表。然后按这套工作流程，帮我设计一张 QPLAY 活动海报。先分析文案、画面比例和信息层级，再给出专业构图方案。正式 IP/Logo 以我提供的最终素材为准，不要臆造。

第三步：如果你有参考图、Logo、正式 IP 原图，就在本次聊天上传。你没有上传的素材，AI 不应假定已经拥有。

第四步：先看构图/方案，再让 AI 生成正式视觉；修改时逐条反馈，如“标题增大、留白增加、不要改角色脸”。

**注意：** 这是让助手在这次任务中**读取并遵循文档**，不是将 Skill 安装成 ChatGPT 内置能力。换一个没有读取该文件的新对话，不保证自动加载。

## 路线 B：如果你在 ChatGPT 里看到了「插件 → 技能」

只有账号与工作空间符合条件、并开放该功能时才会出现。你可以通过「技能 → 创建 → 从计算机上传」，上传符合格式且已检查安全性的 Skill 包。是否可用以你的界面为准。入口说明：https://help.openai.com/en/articles/20001066-skills-in-chatgpt/ 。

## 路线 C：如果以后使用 Codex/Claude Code/Cursor

这些软件有各自的安装目录与安装流程，不能把 GitHub 仓库当成安装程序。安装前，先确认具体软件、操作系统、脚本风险与依赖；建议先熟悉路线 A，再考虑路线 C。

## 三句常用工作指令

**做海报**：
> 按照 QPLAY GitHub 仓库的视觉设计 Skill，制作星际运动主题海报。先给版式和文案层级，做完按检查表复核字形、IP、比例和视觉杂乱问题。

**做墙面**：
> 按照 QPLAY 视觉设计 Skill 设计保龄球墙面。先调取仓库里的空间墙面台账，核对现场尺寸、门的位置和文案；制作前区分概念图与施工出图。

**做网页**：
> 按照 QPLAY 视觉设计 Skill，先研究同类高质量网站，规划明亮、成熟的橙灰白视觉系统及手机端版式，再制作首页。

## 常见误区

- 把文件上传到 GitHub ≠ ChatGPT 自动安装或自动记住。
- 下载 ZIP ≠ 已安装到 Claude Code/Codex/Cursor。
- Skill 让设计流程更规范，但不能保证图像生成的每个汉字、品牌 Logo 和 IP 都一次准确。
- Github 公开仓库不适合存放保密的原始 IP、客户资料和商业设计文件。正式素材优先放在有权限控制的地方。
