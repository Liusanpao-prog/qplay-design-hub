# QPLAY｜全新设计工作区

> 2026-11-03 重启版。这里是独立的新起点，不默认继承历史海报、效果图、提示词或视觉方案。

## 项目是什么
QPLAY｜趣能运动超乐场：一个正在重新梳理的商业空间与品牌设计项目。

**目前唯一确定的工作方式：先定义需求与标准，再出方案，审核通过后才形成正式资产。**

## 从哪里开始（只需 4 步）
1. 阅读 [品牌基础](./brand/BRAND-BASELINE.md)，确认名称、受众、风格和素材是否齐全。
2. 复制 [设计任务模板](./templates/DESIGN-BRIEF.md) 写清楚要做什么。
3. 按 [设计流程](./WORKFLOW.md) 执行，参考 [质量检查表](./DESIGN-CHECKLIST.md) 审核。
4. 把已批准的资料放到 [assets](./assets/README.md)，把交付结果登记到 [deliverables](./deliverables/README.md)。

## 目录说明
- `brand/`：**只放确认过的品牌基本信息**；未确认内容标明待确认。
- `projects/`：每个设计任务一个独立文件夹，避免把所有版本混在一起。
- `assets/`：有授权的品牌原始素材，不用AI草图替代原稿。
- `deliverables/`：审核通过的正式交付清单。
- `templates/`：可重复使用的任务单与验收规则。
- `skills/qplay-design/`：给 AI 助手使用的轻量流程提示，不是设计结论。

## 重要约定
- 历史内容不自动导入；任何旧图只有重新明确指定才会成为参考。
- 不凭空编造 Logo、IP、色号、价格、尺寸、活动权益或其他制作参数。
- 未提供的真实素材一律标记为 `待提供`；生成图不能冒充源文件。
- 画面先关注信息层级、可读性、品牌一致性、商业落地，再考虑装饰。
- 公开仓库不上传未公开商业素材、个人信息、供应商资料或高价值原始资产。
