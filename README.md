## 现阶段品牌定位

- **官方品牌名称：** QPLAY 趣能运动超乐场。
- **定位方向：** 面向年轻客群的综合室内潮流运动与娱乐空间。
- **视觉关键词：** 明亮、干净、成熟、运动感、能量橙、暖白与银灰。
- **避免的表达：** 儿童乐园感、赛博朋克/电竞网吧感、廉价装饰、过量霓虹与大面积黑色。
- **制作原则：** 保持品牌名称一致；正式 Logo、IP 角色不可擅自改造；实物材质/空间出图要可落地。

> ⚠️ 此仓库目前为公开仓库。请勿上传未发布的完整 IP 设定图、未经授权的素材、含个人信息/财务/供应商报价的文档。建议先将仓库改为 Private（私有），再补充内部品牌资产与详细运营资料。详见 [资产与隐私规则](./assets/README.md)。

## 建议工作流

1. 进入 [Issues](../../issues) 新建设计任务，选择相应模板，完整填写目标、尺寸、参考、文案、期限与验收标准。
2. 在 `06-project-management/board.md` 按状态梳理 **待确认 → 待设计 → 设计中 → 待审核 → 待交付 → 已归档**。
3. 规范/代码修改采用分支及 Pull Request；保留修改说明，避免直接覆盖历史。
4. 素材交付先经过文字校对、比例检查、Logo/IP一致性和商业可施工性检查。
5. 正式源文件保存在有权限控制的设计资产库，在这里登记文件编号和安全链接。

## 首批行动

- [ ] 将仓库切换为 Private（如需存放内部设计素材）
- [ ] 上传审核通过的 Logo/字体使用许可/角色原图（仅私有且授权条件满足时）
- [ ] 核准标准色 HEX/CMYK/Pantone 数值，避免从效果图取色
- [ ] 核对空间实测尺寸、门洞/消防/设备遮挡与制作工艺
- [ ] 依据 [设计任务模板](./.github/ISSUE_TEMPLATE/design-task.yml) 建立后续项目

**维护原则：** 已确认事项写入“规范”，有待核验的信息写入“待确认”；不把参考图、AI 草图或记忆中的数值视为最终制作源文件。
