# 06｜设计任务管理体系

## 任务入口
优先使用 GitHub **Issues**，从菜单选择“设计任务”“品牌资产审核”“网页开发任务”模板。另用 [任务看板](./board.md) 跟踪阶段。

## 状态流转
待确认 → 待设计 → 设计中 → 待审核 → 待交付 → 已归档

遇到缺少正式素材、尺寸或文案，保持“待确认”，不得按猜测直接标记已交付。

## 优先级
- **P0 紧急**：影响已定场地施工或上线的重大问题。
- **P1 高**：正式交付窗口内的重要设计/规范。
- **P2 常规**：常规业务推进。
- **P3 研究**：参考调研、探索与长期优化。

## 建议标签（可在仓库 Issues 设置里创建）
`type:brand`、`type:ip`、`type:space`、`type:collateral`、`type:web`、`priority:P0`～`priority:P3`、`status:needs-input`、`status:review`。

## 每周例会
星期一核对任务范围、输入齐备程度与下周交付；星期五复盘审核意见、版本与遗留问题。不要以完成预览图等同于施工文件审核完成。
