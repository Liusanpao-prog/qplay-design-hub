# QPLAY 设计任务看板｜初始化

> 实际任务以 GitHub Issues 为准，本页只保存工作流与当前阶段计划。

| 阶段 | 意义 | 准入/退出 |
| --- | --- | --- |
| 待确认 | 缺需求、尺寸、原图或负责人 | 输入齐备才进入待设计 |
| 待设计 | 已批准需求，尚未制作 | 开始设计、指定版本编号 |
| 设计中 | 草案、调研与打样 | 附预览+检查记录提交审核 |
| 待审核 | 品牌/文案/施工复核 | 反馈通过或退回 |
| 待交付 | 导出、印前与最终校对 | 交接文件登记完整 |
| 已归档 | 完成、可追溯 | 保存定稿、版本、确认人 |
