# 04｜物料设计与交付规范

## 类型
品牌海报 / 店内导视 / 会员卡 / 员工物料 / 兑换券 / 活动宣传 / 社交媒体主视觉 / 墙面喷绘 / 网站宣传资产。

## 设计需求提交
- 品牌与项目编号、使用门店/位置
- 最终文案（逐字校验）与活动有效期
- 尺寸与单位（cm、mm、px 等）、横竖版、印刷工艺
- Logo/IP 已核准素材编号及有无版权限制
- 参考图：可借鉴的风格点与不可沿用的内容
- 留白区、裁切/安装条件、目标受众、交付时间

## 交付前检查
- [ ] 中文字形准确完整，价格/时段/券规则无误
- [ ] 品牌命名与 Logo 官方原稿一致
- [ ] 角色未走形或混用形象
- [ ] 印刷比例、分辨率、出血、颜色模式与制作厂确认
- [ ] 图像未含未经授权的商标、人物肖像或素材
- [ ] 原稿/可编辑文件与预览稿分开归档
- [ ] 文件名版本一致并有审核人/日期

## 推荐命名
`QPLAY_项目名_位置或尺寸_版本_YYYYMMDD.ext`
例如 `QPLAY_保龄球正面墙_7000x1500mm_V01_20261103.pdf`。
