# 05｜网站开发

## 目标
先建设**静态品牌展示官网/数字品牌手册**，围绕年轻潮流运动场馆的氛围与业务信息制作干净、快速、响应式的页面。会员账号、真实预约、支付和后台等需要额外开发/服务，不在本基础框架默认范围内。

## 建议页面
1. 首页：QPLAY 主张、视觉、核心业态、场馆入口
2. 品牌介绍：定位、场景、设计语言
3. 游玩项目：电竞、VR、保龄球、主机、运动项目等
4. 场馆与空间：以审核后的实景或明确标识的概念效果图展示
5. 联系方式：仅发布官方核准的地点、电话与营业信息
6. 品牌规范展示（如公开使用权限允许）

## 开发规则
- 默认移动端优先、可访问性和加载速度优先。
- 禁止将未发布 IP 原图、供应商资料直接放进公开网站的代码库。
- 官网文案与品牌手册统一；不要编造票价、地址、联系电话和开放时间。
- 部署前逐项完成检查清单：[launch-checklist.md](./launch-checklist.md)。
