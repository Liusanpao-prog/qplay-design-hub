# 01｜品牌视觉规范

**品牌正式中文名：趣能运动超乐场；英文主标：QPLAY。** 禁止使用旧名“趣能超乐场”。

## 定位
面向约 16–30 岁的年轻消费群体，主打大型室内潮流运动与综合娱乐空间：主机游戏、射箭、射击、台球、保龄球、电竞、VR、碰碰车、影院等。

## 品牌视觉共识
- 主视觉：能量橙 + 银灰金属 + 暖白/浅灰，少量深石墨灰。
- 气质：成熟运动潮流、干净、明亮、有空间质感。
- 避免：儿童游乐园风、赛博朋克、网吧感、满屏霓虹、廉价厚重3D、过量斜切装饰、大面积黑色。
- 画面必须优先保障信息可读性、字形完整性、制作用途与实景可施工性。
