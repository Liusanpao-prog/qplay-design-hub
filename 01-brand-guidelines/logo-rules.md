# QPLAY Logo / 品牌命名规范

## 已确认
- 英文主标：**QPLAY**；中文副标：**趣能运动超乐场**，采用上下组合，英文优先。
- 英文字标视觉：能量橙、平面几何运动字体、整体略右倾约 6–8°、有克制的几何切角。
- 禁止将 Logo 做为厚描边、发光、伪3D/浮雕效果；禁止随意重绘字形。
- 正式中文必须准确呈现“趣能运动超乐场”，尤其检查“趣”字。
- 品牌手册封面不使用狐狸 IP 图形；Logo 应按正式品牌源文件应用。

## 使用/验收
1. 首选原始矢量源文件；禁止仅用生成式图像重新拼写 Logo。
2. 留出充分安全边距；确保从实际观看距离可读。
3. 单色、反白、印刷和实景发光字需各自打样验证。
4. 未提供精确网格/安全距时，不擅自规定具体倍数。
