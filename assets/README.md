# 设计资产管理 / 安全规则

本目录默认只存**使用说明与空白清单**。当前仓库为 Public（公开），未经授权不得上传完整狐狸角色原图、矢量商标源文件、设计师源文件、内部价格、合同或客户隐私。

## 推荐做法
- 正式图片/PS/AI/CAD/视频在具备权限控制的团队素材库管理；GitHub 中记录文件 ID、版本、审批状态及安全链接。
- 仓库改为 Private 且授权明确后，可择需保存轻量 WEB 资产（SVG/WEBP/PNG 等）；大型二进制素材不适合普通 Git 版本管理。
- 如需保存大型原档，评估 Git LFS、云盘与访问控制方案；不要把私密文件放进公开 Git 历史。
- 禁止上传 API key、登录信息、未授权字体与侵权图片。
